# 🤖 AI Chat App (Spring Boot + HuggingFace)

A simple REST-based AI chat application built using **Spring Boot** that connects to **HuggingFace AI models**.  
This project provides a backend API where you can send prompts to an AI model and receive chat responses, with optional conversation history.

---

## 🚀 Features

- Send chat messages to an AI model
- Maintains chat history across messages
- Reset conversation anytime
- Automatic retry system (in case API fails)
- Safe fallback response when HuggingFace is unavailable
- Cross-origin enabled for connecting from any frontend
